Osmette 5002 A — Quick Protocol

Freezing-point osmometer. 0.2–2.0 mL per read, ~60 sec each.
  1. Turn it on. Front panel, lower left — flip the OPERATE switch to OPERATE.
    • Wait ~15 min until the red COOL light starts cycling on and off.
  2. Check the blue bath fluid.
    • Peek into the well. Fluid should be at its original level.
    • If low, slowly pour in OSMETTE bath fluid (blue) until a little overflows into the plastic tray on the right. Only use OSMETTE antifreeze.
  3. Run a sample.
    • Make sure RANGE is on 0–2.
    • Pipette into a clean, dry sample tube — no bubbles:
      • Big tube (2.0 mL): pipette 2.0 mL
      • Small tube (0.2 mL): pipette 0.2 mL (0.25 mL ideal; 0.3 mL is even more forgiving)
    • Raise the head, swap in your tube, lower the head smoothly.
    • Walk away for ~60 sec. Display counts up from negative → 1000 → seeds → READ light comes on → number locks.
    • That number is your mOsm/kg.
  4. Between samples.
    • Raise head, pull tube, very carefully wipe probe + seed wire with a Kimwipe (not gauze).
    • Put the next tube in, or park a clean empty tube in the well.
  5. Shut down.
    • Clean empty tube in the well, head lowered into it, OPERATE switch to OFF.
Watch out for:
  • If RANGE is on 1–3, add 1000 to the reading.
  • Never force a tube into a frosted well — turn off for a few min to defrost.
  • Never lower the head onto a tube with ice in it (breaks the probe).

Checking calibration

Daily, or before a run of unknowns.

  • Pour a 290 mOsm CON-TROL ampule (or 500 mOsm standard) into a clean, dry tube — never pipette straight from the bottle.
  • Pipette from that tube into a fresh sample tube (2.0 mL or 0.2 mL).
  • Run it like a normal sample.
  • Should read within ±2 mOsm of label value. If not, recalibrate.

Recalibrating

Only if the check fails.

First range (0–2000 mOsm)

  1. RANGE → 0–2, OPERATE → SPECIAL.
  2. Run a 500 mOsm standard. Just before READ light comes on, adjust CAL I with the screwdriver so display reads 500.
  3. Switch back to OPERATE, freeze a fresh 500 standard to verify.
  4. Repeat with a 100 mOsm standard, adjusting CAL II to read 100.

Second range (1000–3000 mOsm) — only if you actually use this range

  1. RANGE → 1–3, OPERATE → SPECIAL.
  2. Run a 1500 mOsm standard, adjust CAL III so display reads 500 (remember +1000 rule).
  3. Switch back to OPERATE and verify with a fresh 1500 standard.
